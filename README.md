# منصة التميز والتحصيل الدراسي — مجمع الأمير متعب بن عبدالعزيز التعليمي

## الملفات
- `index.html`: الواجهة العربية المتجاوبة.
- `app.js`: منطق المؤشرات والتحليلات والخطط والتقارير.
- `config.js`: إعداد الاتصال بالسحابة.
- `schema.sql`: الجداول وصلاحيات الوصول (RLS).

## تجربة فورية
افتح `index.html` في المتصفح، أو ارفع الملفات إلى مستودع GitHub Pages. ما دام `config.js` دون إعدادات، تعمل نسخة تجريبية ببيانات محلية في المتصفح **فقط**، دون حسابات حقيقية أو مزامنة بين الأجهزة. لا تستخدم معلومات شخصية حقيقية للطلاب في هذا الوضع.

## تفعيل الحفظ السحابي وحسابات المعلمين
1. أنشئ مشروعًا في [Supabase](https://supabase.com) تحت حساب رسمي معتمد للجهة.
2. افتح SQL Editor ونفّذ محتويات `schema.sql` في مشروع جديد. إذا كانت الجداول أو السياسات موجودة سابقًا، راجعها قبل إعادة التنفيذ.
3. من Project Settings / API انسخ **Project URL** و**anon/publishable key** فقط إلى `config.js`، ولا تضع `service_role` أو أي مفتاح سري في الملفات المنشورة.
4. من Authentication > Users أنشئ حسابًا لكل معلم وحساب المدير باستخدام بريد وكلمة مرور فريدين. عطّل التسجيل العام غير المصرح به، وفعل سياسات كلمات مرور قوية وMFA إن توفرت.
5. انسخ UUID لكل مستخدم وأضفه إلى جدول `public.profiles` باستخدام SQL Editor. عيّن الدور `admin` للمدير فقط و`teacher` للمعلمين. لا تُنشئ دور المدير عبر صفحة تسجيل عامة.
6. ارفع الملفات الأربعة (عدا `schema.sql` و`README.md` إن أردت) إلى GitHub Pages؛ الصفحة ستتصل بقاعدة Supabase مباشرة، مع حماية السجلات بسياسات RLS.
7. جرّب حساب معلم وحساب مدير من جهازين مختلفين، وتأكد أن المعلم لا يستطيع رؤية بيانات الآخرين، بينما يستطيع المدير الاطلاع على الجميع.

## ملاحظات أمنية ووظيفية
- لا تستخدم أسماء الطلاب أو أرقام هوياتهم أو بياناتهم الصحية؛ المنصة مصممة لتحليلات مجمعة على مستوى الشعبة.
- بيانات العرض التجريبي تُخزّن في localStorage، بينما بيانات الوضع السحابي تُخزّن في Supabase.
- لا توجد حسابات أو قاعدة سحابية مُنشأة مسبقًا؛ يتطلب التفعيل إعداد مشروعك وبيانات المستخدمين.
- تصدير CSV متاح، وطباعة الصفحة تتيح الحفظ PDF من المتصفح.
- المؤشرات الإجمالية تجمع أعداد الطلاب عبر التحليلات، وقد يتكرر احتساب الطالب إذا ظهر في سجلات متعددة.
- قبل الاستخدام الرسمي، راجع متطلبات أمن المعلومات وحوكمة البيانات في وزارة التعليم والجهة المشرفة، وحدد سياسة نسخ احتياطي واحتفاظ وصلاحيات.
